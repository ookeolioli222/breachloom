# Breachloom — Web Security & Bug Bounty Labs in the Browser

**Practice web and API security in your browser.** No VM, no Docker, no broken lab setups — open a
challenge and start in seconds. Every scenario is a safe simulation of a fictional app, so you learn real
techniques without touching anyone's systems.

🔗 **Live: https://breachloom.com**

## What's inside
- **81 CTF challenges** across IDOR/BOLA, XSS, SQL injection, SSRF, JWT, CSRF, prototype pollution,
  NoSQL injection, GraphQL BOLA, file upload and race conditions.
- **18 CodeOps missions** — you don't just exploit the bug, you *fix the vulnerable code* and the server
  verifies your fix.
- **11 multi-step attack chains** — e.g. open redirect → OAuth code leak → account takeover, the way real
  bug-bounty reports read. Each chain starts with an operation brief and runs against a detection budget.
- **Flashcards, quizzes and a 100-chapter theory library** to lock in the mechanism, not just the payload.
- **AI/LLM security** — indirect prompt injection, insecure output handling, excessive agency (OWASP LLM Top 10).
- Available in **English, Polish, German, Spanish and Russian**.

## Who it's for
Beginners who want a structured path into bug bounty, and developers who want to *see* how these bugs
work and how to fix them. Challenges start easy and build up.
