# Breachloom — Web & API Security Training in the Browser

**Practise web and API security in your browser.** No VM, no Docker, no lab setup. Every scenario is a safe
simulation of a fictional application, so you learn real techniques without touching anyone's systems.

**Live: https://breachloom.com** · [Free case](https://breachloom.com/) · [Blog](https://breachloom.com/blog/) · [Bug bounty roadmap](https://breachloom.com/bug-bounty/)

## Start with a free case

An invoice you do not own is returned by the API. In the free case you change one number in the request,
read another customer's data, and add a single condition in the code that blocks it. Every case ends with
evidence and a repair, not just a flag. No account or card is needed for the demo.

## What is inside

| Area | What you do |
| --- | --- |
| **Challenges (96)** | Request/response work, code review, tokens and controlled race conditions: IDOR/BOLA, SQL injection, XSS, SSRF, JWT, CSRF, NoSQL injection, GraphQL, file upload, prototype pollution and AI/LLM security. |
| **CodeOps (18 missions)** | Fix vulnerable code taken from real incident patterns. The server runs regression tests: the exploit must stop working and normal use must keep working. |
| **Blind investigations (40)** | A working fictional app and no hints. Find the problem, prove it with a request, then verify the repair. Tasks use a proxy-style workspace: browser, HTTP history and Repeater. |
| **Advanced labs (34)** | Web/API, SOC, DFIR and cloud scenarios, from request smuggling and OAuth flows to IAM, Kubernetes and log analysis. |
| **Operations (2)** | Multi-step labs with a mission briefing: investigate a running application, collect evidence, then write the report. |
| **Learn** | Academy lessons, a library of about 100 theory chapters, a wiki of 28 vulnerability classes and 391 flashcards with spaced repetition. |
| **Bug bounty** | Scope, reconnaissance, report writing and a report template. |

Available in **English, Polish, German, Spanish and Russian**. The free tier lets you try the platform; Pro
unlocks the full catalogue.

## Who it is for

Beginners who want a structured path into bug bounty, and developers who want to see how these bugs work and
how to fix them. Tasks start easy and build up. All targets are controlled simulations: use the techniques only
on your own assets, in legal labs or inside the official scope of a bug bounty programme.
